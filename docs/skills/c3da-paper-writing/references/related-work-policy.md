# Related Work Policy

Related Work should be written early, while experiments are still running.

It serves two purposes:

1. establish scientific context;
2. test whether the current proposed method is actually novel.

## Search groups

Recommended categories:

1. ASTE;
2. generative ASTE;
3. cross-domain ASTE / ABSA;
4. pseudo-label domain adaptation;
5. label-to-text / data augmentation;
6. syntax-aware ABSA;
7. graph-based ABSA;
8. target-domain adaptation.

Only categories relevant to the final story need to remain in the final paper.

## Verification

For each paper verify:

```text
TITLE
AUTHORS
YEAR
VENUE
TASK
DOMAIN_SETTING
TARGET_SUPERVISION
METHOD
METRIC
RESULT_SOURCE
CODE_AVAILABILITY
RELEVANCE
```

## Rules

Do not cite from memory.

Do not describe a non-ASTE paper as an ASTE baseline.

Do not transfer numerical claims across different tasks.

Do not create strawman descriptions.

Read the original source for any paper central to the novelty claim.

Syntax/graph literature should be researched especially carefully if a graph-based candidate remains active.
